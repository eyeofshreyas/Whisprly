# Security Policy

## Supported Versions

Currently, only the latest version of Whisprly is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please do **NOT** report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in Whisprly, please report it privately to the repository owner or maintainers. 

We will try to acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. If the vulnerability is accepted, we will work on a fix and publish a security advisory.
