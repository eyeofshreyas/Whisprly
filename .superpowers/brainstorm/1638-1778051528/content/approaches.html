How should the background setup work?

Three implementation approaches — pick the one that feels right

A

Rust-native (recommended)

On startup, Rust checks if Ollama is installed and gemma4-4b is pulled. If not, it runs winget install Ollama.Ollama then ollama pull gemma4-4b — streaming progress back to the frontend via Tauri events. Frontend shows the bottom bar from that stream.

Pros

  • No extra dependencies
  • Fits existing Tauri event pattern
  • Full control over progress

Cons

  • Requires winget (built into Windows 11)
B

Download Ollama installer directly

Instead of winget, Rust downloads the Ollama .exe installer directly from ollama.com, runs it silently, then pulls the model. More reliable if friends don't have winget updated.

Pros

  • Works even if winget is outdated
  • No dependency on winget

Cons

  • Must hardcode a download URL
  • More complex install flow
C

Setup Python script

A Python script handles everything — checks Ollama, installs it, pulls the model. Rust just runs the script and forwards its output as progress events.

Pros

  • Easy to modify without recompiling

Cons

  • Requires Python — which friends may not have
  • Defeats the purpose of a self-contained installer
